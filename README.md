# 听见中轴 · 线上博物馆（静态原型）

移动端优先的静态站点，无构建步骤。

- 预览：`python3 tools/serve.py 8765`，浏览器打开 `http://localhost:8765/`（也可直接双击 `index.html`）。**不要用 `python -m http.server`**：它不支持 HTTP Range，视频拖不动进度条；`tools/serve.py` 已补上。正式部署的服务器需开启 Range（Nginx / OSS / CDN 默认都支持）
- 视觉：色彩取自 logo 与 IP「凸嘟」，集中在 `css/style.css` 顶部的 `:root`，换视觉参考时优先改这里
- 内容：`js/data.js`（结构与占位）、`js/sounds.gen.js`（单个声音文案，由策划文档生成）、`js/project.gen.js`（项目文案，**按四份定稿 PDF 手工维护**：工作坊简介 / 设计思路 / 特色描述 / 展区设计方案，修改请以 PDF 为准）
- 重新生成声音文案：`python3 tools/gen_sounds.py`（读取由 docx 抽取的 `/tmp/doc.txt`、`/tmp/sec.json`）；不要用它覆盖 `project.gen.js`
- 截图自检：`python3 tools/shots.py dig explain s01`（需 Chrome）

## 导入音频

放到 `assets/audio/`，文件名即生效，无需改代码：

| 文件 | 内容 |
|---|---|
| `s01.mp3` … `s15.mp3`（或 `s10/s13–s15.m4a`） | 15 个声音，编号见 `js/data.js` 的 `SOUNDS[].no` |
| `m-north.mp3` `m-midNorth.mp3` `m-midSouth.mp3` `m-south.mp3` | 四首二创音乐 |

`s10`、`s13`–`s15` 当前为 `.m4a`（源文件格式）；其余为 `.mp3`。扩展名映射在 `js/app.js` 的 `AUDIO_EXT`。文件缺失时，播放器会用“模拟进度”演示交互并提示一次。

## 序·总览的图与视频

- 思维导图：`assets/img/mindmap.jpg`，点击进入灯箱，可左右滑动看清文字。
- 背景地图：`assets/img/bg-axis-map.jpg`（取自官网地图，1800px 宽）。

## 景点照片

放到 `assets/img/places/pNN.jpg`（NN 为声音编号，如 `p11.jpg`），同名覆盖即替换，缺失时自动显示“照片待导入”占位。
目前 p01–p10、p13–p15 取自策划文档内的配图；p11（钟鼓楼）、p12（广化寺）取自 Wikimedia Commons，**发布前请确认来源与授权**。景色场地图见 `assets/img/scene/NN.jpg`。

## 声景长卷

`assets/img/skyline-scroll.png` 提取自《重磅！声景卷轴.ai》第 3 画板（仅保留金色天际线图层，透明底）。
各声音在长卷上的位置在 `js/app.js` 的 `POS`（0 = 最南，1 = 最北）。

## 交互与动效

参照“北京中轴线”官网手机端（整屏翻页、手势进入、渐进点亮、轮播联动）。代码分两处：`js/motion.js`（转场 / 入场 / 手势）、`css/motion.css`（状态样式）；视图相关逻辑在 `js/app.js`。

| 位置 | 交互 |
|---|---|
| 入口 | 沿中轴依次展开；上滑 / 滚轮 / ↓ 键进入（等同“有声进入”） |
| 页签切换 | 按 序→挖→阐→创→传 的先后整屏上翻 / 下翻；进入 / 离开声音详情为横向滑入 |
| 挖掘 · 长卷 | 进入视野后自动由南向北行进，触碰即停；走过之处由灰转金，声音点逐个亮起；点景点居中并弹出信息卡（可关闭）；标题 + 长卷 + 分段滑动条（南段 / 中段南部 / 中段北部 / 北段 / 新北段，可点按拖动）一屏收齐，长卷高度随屏幕自适应 |
| 阐释（整页） | 一屏不滚动：标题“声音与场所”+40字简介，“展开”以渐变蒙层叠加（点击渐变处收起）；卡片/列表切换仅替换下方主体（淡入淡出），标题与简介不动 |
| 阐释 · 列表 | 按 南段/中段南部/中段北部/北段/新北段 五段，分段条固定在上，列表在其下方容器内滚动并随滚动高亮；无筛选行 |
| 声音页 `#/audio/NN` | 挖掘信息卡“详情”进入；对应图片自动轮播（`assets/img/audio/NN-1.jpg` 放入即生效）、聆听（波形进度）、声音介绍（取“对应场景与依据”）、声音现场（景色场地 `assets/img/scene/NN.jpg` + 调研图片 `assets/img/survey/NN-k.jpg`，仅 `SURVEY` 中登记过的声音展示，无图不占位）；左右滑动切换相邻声音。阐释详情页（`#/sound/NN`）不再含“对应场景与依据” |
| 阐释 · 卡片 | 横滑莲瓣圆章（Coverflow），背景与分段标签随声音单元联动；右上角可切回“列表” |
| 创化 · 总览 | 先看三类成果：二创音乐 / IP · 文创 / 场景活动，三张大卡一屏看全，点击进入详情 |
| 创化 · 详情 | 顶栏常驻“‹ 创化”返回 + 三段切换（红色滑块跟随），内容左右滑入；页内左右滑动也可切类；页尾“下一类成果”入口 |
| 创化 · 二创音乐 | 黑胶唱片舞台：播放时唱片转动、波纹外扩、波形随节奏起伏；左右滑动 / 上下一段切曲（唱片带方向滑入、背景景色交叉淡化）；南北四站轴线随播放填充；站点可点选；连播自动跟随 |
| 创化 · IP · 文创 | 五形态“凸嘟”整屏视差轮播（背景慢、角色快、题牌垂落、点角色会弹并飘出 ♪）；头像选择器联动；色板点按复制；文创图集横滑 + 全屏灯箱（左右滑 / 下拉关闭） |
| 创化 · 场景活动 | 三张活动卡随滚动叠牌：前一张被压住时缩小变暗（活动图当前用 IP 场景图作示意，标注“活动图待导入”） |
| 声音详情 | 左右滑动 = 往北 / 往南；入场时题牌垂落、图片缓缩 |
| 全站 | 内容随滚动依次浮现；底部标签滑动指示；系统“减少动效”下全部关闭 |

转场用 Web Animations API，无依赖；`file://` 可直接打开。
